Case study

Credit risk modeling for card payment default

Four model comparisons, an ablation on repayment history and the business cost of missed risk versus false alerts.

PythonClassificationRandom ForestRisk Analytics
Technical case · Original project + portfolio decision exercise

From ranking risk to choosing an action

I compared a class-weighted logistic regression with a class-weighted random forest on all available features and on repayment history alone. The substantive result is a trade-off: the full forest was more precise, while the full logistic model caught more defaults at its reported operating point.

03 / Portfolio extension: review-cost explorer

Choose how costly a missed default is relative to an unnecessary review. This calculator converts the reported, rounded precision and recall into approximate counts for a hypothetical 1,000-client sample with the original 22.12% default rate. It compares the four reported operating points; it does not tune a new threshold or retrain the models.

One unnecessary review = 1 unit. Lower total is preferable under the selected assumption.

The comparison loads when JavaScript is available.

Approximation: TP = 1,000 × 0.2212 × recall; FN = 221.2 − TP; FP = TP × (1 / precision − 1); total cost = missed-default cost × FN + FP. Rounded source metrics and an assumed prevalence make the counts illustrative.

04 / Reproduce the calculation

The code below is a new portfolio analysis of the four reported operating points. It does not retrain models or substitute for the original training code, which was not supplied with the presentation.

prevalence, sample_size = 0.2212, 1000
tp = sample_size * prevalence * recall
fn = sample_size * prevalence - tp
fp = tp * (1 / precision - 1)
review_cost = missed_default_cost * fn + fp

Interpretation boundary

A one-year Taiwan sample does not establish how the models perform on current applicants in another market. Calibration, fairness evaluation, cost-based threshold selection and drift monitoring would need new data. The figures above do not imply that those steps were performed in the course project.
