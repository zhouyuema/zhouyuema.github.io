Case study

Financial well-being and happiness in the United States

An independent R and Shiny analysis, with a reproducible group explorer on the original project sample.

RShinyPlotlyData Storytelling
Technical case · Independent R + Shiny project

Two outcomes, one careful comparison

I built the analysis and both Shiny dashboards independently. The project tests whether a group can appear financially secure without reporting the same level of subjective happiness; it keeps the constructs separate even when the scores share a visual axis.

Data quality

Survey response codes below the valid range are treated as missing before computing group means.

Comparable display

The happiness response is displayed on a 0–100 scale using (SWB_1 − 1) / 6 × 100; rescaling does not equate the two measures.

Interrogate groups

R/ggplot2 establishes the overall story; Plotly and two Shiny apps let a reader compare demographic and income–education subgroups.

01 / A real transformation from the R Markdown source

df_viz1 <- df %>% mutate(
  FWBscore_clean = ifelse(FWBscore < 0, NA, FWBscore),
  SWB_1_clean    = ifelse(SWB_1 < 1, NA, SWB_1),
  SWB_100        = (SWB_1_clean - 1) / 6 * 100
)

Excerpt from the submitted Rmd. Missingness and the choice of scale matter before a visual comparison is meaningful. This is a descriptive survey analysis; unweighted group averages should not be read as adjusted population estimates.

02 / Portfolio extension: reproducible group explorer

I rechecked the 6,394-row project CSV using the same valid-score rules. Five financial well-being codes and 31 happiness codes were invalid; 6,363 rows contain both measures. Choose a grouping to compare unweighted sample averages and see each cell's sample size.

The comparison loads when JavaScript is available.

Both scores are displayed on a 0–100 scale for side-by-side inspection. These raw group means do not account for survey weights, uncertainty, confounders or causal effects.
