Technical case · Team project + portfolio reanalysis

One dataset, three analytical questions

I led a five-person project using the same cleaned country sample in Dash, Power BI and Tableau. The technical task was to make three tools answer distinct questions without quietly changing the countries behind the comparisons.

01 / Cleaning contract and reproducible check

Blank values became missing; analysis fields were converted to numeric; 12 exact duplicates were removed; life expectancy and CO₂ per person were derived; and countries missing variables required for the three questions were removed. The prepared 134-row CSV and a short verification script are downloadable below. Its ISO-2 code is missing for one country; the six measures used here are complete.

for x, y in PAIRS:

Interpretation boundary

The 134-country complete-case sample excludes countries with missing fields. Tableau's four quadrants use sample medians, not official sustainability ratings; national emissions and forest cover do not tell us whether one causes the other.
